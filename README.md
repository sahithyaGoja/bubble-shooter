# Bubble Shooter

A simple browser-based Bubble Shooter game built with plain HTML, CSS, and JavaScript.

## How to run

1. Open `index.html` in a browser.
2. Move the pointer to aim.
3. Click the canvas to fire bubbles.
4. Match 3 or more bubbles of the same color to clear them.

## Files

- `index.html` — page structure
- `styles.css` — game styling
- `game.js` — game logic and rendering

## Controls

- Mouse or touch: aim and shoot
- Restart button: starts a new game

## Notes

This version is a lightweight, playable prototype designed for easy customization and extension.
